# LOCAL-WORK-GOVERNANCE — Work tracking governance map

## Scope

Rules, schemas, validation, and agent instructions governing `TODOS.md`, local
ticket lifecycle, and durable private work records under `.scratch/`.

## Boundaries

This workstream defines how work is tracked; it does not own the product,
release, documentation, or tooling work being tracked. Those tickets remain
in the workstream whose domain owns their outcome.
