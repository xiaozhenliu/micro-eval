# Release Evidence - v0.2.0 Phase 2

## Scope

Version `0.2.0` prepares the Phase 2 local-first release:

- pass@k / pass^k aggregation and cost-source reporting;
- sibling `decision.json` persistence with legacy embedded-decision fallback;
- optional trace capture with process fallback and Langfuse adapter boundary;
- Phase 2 review UI at `/run/[id]/review` plus manifest-bound trace lookup API;
- default-off supplemental LLM judge path using DeepEval only as an optional adapter.

No dev-to-main publication, tag, or push was performed as part of this evidence record.

## Security evidence

- Trusted subprocess execution remains argv-only; preflight grep found no `create_subprocess_shell` or `shell=True` in trusted paths.
- Trace and judge integrations are default-off optional extras.
- Optional SDK usage is behind adapter/importlib boundaries; direct `import deepeval` / `import langfuse` was not found in trusted implementation paths.
- Secrets remain environment-only via declared `MICRO_EVAL_SECRET_*` names and are not recorded in config, artifacts, release docs, or dependency inventory.
- UI/API trace and artifact reads remain manifest/run-bound rather than arbitrary filesystem reads.

## Known release gaps

- Langfuse cost extraction is best-effort and optional.
- Token-count × price-table cost estimation is not implemented.
- Calibrated larger-sample statistics beyond current pass@k / pass^k are not implemented.
- ATIF import/export and hosted collaboration remain out of scope.
- No dedicated Vitest suite is configured for the UI; lint/build and Python contract coverage remain the release checks.
