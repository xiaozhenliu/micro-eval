# Release Evidence - v0.2.1 Test Architecture Hardening

## Scope

Patch release on top of v0.2.0 (Phase 2). No new product features; this
release hardens the test architecture and example assets:

- Coverage gap closure: Langfuse provider degradation/cost-ladder/redaction,
  deterministic validator branches (path-escape, command, redaction),
  run store boundaries (root escape, legacy fallback).
- Cross-language API route contract tests with Python-generated Phase 2
  fixtures validated by both Pydantic and zod.
- Phase 2 golden-path e2e (trace + mock judge + decision.json + report cost
  source), frozen v0.1.x legacy run fixture with dual-side compat tests,
  CLI failure-path contracts, Decision Surface honesty assertions.
- Examples updated to surface Phase 2 (mock path: 3 repetitions, process
  trace, pass@k in decision.json; documented trace/judge blocks).

## Validation

- `uv run pytest -q`: 122 passed
- `cd ui && npx vitest run`: 18 passed
- `cd ui && npm run lint && npm run build`: pass
- `python examples/run-example.py`: exit 0; decision.json contains
  pass@k for k=1..3 with empty stats caveats and 3 process TraceRefs
- `grep -RInE 'create_subprocess_shell|shell=True' src tests ui/src examples`:
  zero matches
- `uv build`: micro_eval-0.2.1 wheel + sdist built
- Version consistency check: pass (all surfaces at 0.2.1)

## Security

- No new subprocess, env injection, or outbound data paths in this release.
- Test fixtures contain no real credentials; secrets-redaction behavior is
  covered by new negative tests (judge prompt, trace summary, validator
  command output).
- Workspace boundary checks (cell dir escape, project root escape) now have
  explicit contract tests.
