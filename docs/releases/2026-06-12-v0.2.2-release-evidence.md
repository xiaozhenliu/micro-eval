# Release Evidence - v0.2.2 CI Pipeline and Contract Golden Mechanism

## Scope

Patch release on top of v0.2.1. Infrastructure only; no product feature or
schema changes:

- GitHub Actions CI pipeline with five jobs: pytest + 75% coverage gate on
  Python 3.11/3.12, compileall + shell-injection grep gate, golden fixture
  sync check, UI lint/vitest/build, example smoke. No repository secrets;
  workflow token is read-only.
- Contract golden mechanism: `scripts/generate-golden.py` deterministically
  generates all cross-language contract fixtures under
  `tests/contract/golden/`; pytest validates round-trip, idempotency, and
  no-secret content; vitest consumes the same files with strict
  stripped-field detection. Hand-maintained UI fixtures removed.

## Validation

- `uv run pytest -q`: 147 passed (coverage 77.8%, gate 75%)
- `cd ui && npx vitest run`: 41 passed
- `cd ui && npm run lint && npm run build`: pass
- Golden regeneration idempotency: second run produces zero diff
- Drift-injection experiments (both directions observed red, then reverted):
  generator change without regenerated golden fails the sync check;
  golden field undeclared in zod fails the strict vitest check
- `python examples/run-example.py`: exit 0
- shell-interpolation grep gate: zero matches
- `uv build`: micro_eval-0.2.2 wheel + sdist built
- Version consistency check: pass (all surfaces at 0.2.2)

## Security

- CI workflow defines no secrets and uses `permissions: contents: read`.
- Golden generator reads no environment variables; generated fixtures are
  asserted to contain no `MICRO_EVAL_SECRET` markers or home-directory paths.
- No new subprocess, env injection, or outbound data paths.
