# Release Evidence - v0.4.3 Security Audit Remediation

## Scope

Security patch release on top of v0.4.2. No product feature or schema changes;
the release resolves the 2026-07-07 security audit
(`docs/security/2026-07-07-security-audit.md`, dev-only, excluded from `main`).

- **H1 / GRO-172** — `template_id` path traversal at `POST /api/workspaces`
  (charset allowlist + `resolve()` prefix check at the Python boundary).
- **M1–M7 / GRO-173–179** — Host-header allowlist / DNS rebinding, Content-Type
  enforcement, local evaluate route gated in serve mode, bridge subprocess leak
  window, dead-agent scoring guard, `worker.pid` identity + flock race, and the
  audit-report leak-to-main exclusion.
- **L1–L10 / GRO-180–189** — eval.yaml symlink write-through, pure-dot runId
  traversal, persisted-text redaction (kernel stderr, worker exceptions,
  conversation user turns), bridge stderr drain cap, template hardlink/symlink
  detection, worker workspace-ID validation, short-secret over-redact guard, and
  overrides whitelist narrowing.
- **I1–I5 / GRO-190–194** — error-path leak sanitization, string-interpolation
  removal (env var passing), LLM-judge injection note, Modal env allowlist,
  run_store JSON narrowing.

Each fix was reviewed by codex (gpt-5.4/5.5, xhigh) and landed in its own commit
with per-issue security checklists; see `CHANGELOG.md` §0.4.3 for the full list.

## Security (secrets / workspace / shell interpolation)

- **Secrets redaction**: This release aggregates fixes that *strengthen*
  redaction — kernel error stderr, worker exceptions, and conversation user
  turns now pass through `Redactor.from_env()` before persistence (L3/L4/L6),
  short secrets below 4 chars are skipped to avoid pathological over-redaction
  (L9), and error responses are path-sanitized (I1). The release commit itself
  adds no new secret-bearing surface. Dependency inventory records no
  environment variables, tokens, or credential paths.
- **Workspace boundary**: Fixes tighten the workspace/template boundary —
  `resolve_template_dir()` charset allowlist + prefix check (H1), worker
  workspace resolution via `WorkspaceManager.resolve_path` (L8), eval.yaml
  symlink write-through closed with lstat+realpath+prefix (L1), template
  hardlink/symlink detection (L7). No boundary is loosened.
- **Shell interpolation**: No new subprocess or shell string interpolation is
  introduced; I2 removes a `JSON.stringify`-into-Python interpolation in favor
  of env-var passing. Contract test `test_execution_contract.py` continues to
  assert the kernel spawns no processes directly.
