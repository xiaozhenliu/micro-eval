# Development Log - v0.2.2 CI Pipeline and Contract Golden Mechanism

## Summary

Implemented the confirmed plan
(`docs/superpowers/plans/2026-06-12-ci-and-contract-golden-plan.md`) in two
slices: GitHub Actions CI and a generated golden-fixture mechanism for
cross-language contracts. Implemented by a sonnet subagent, reviewed and
hardened in the main session. Version bumped to 0.2.2.

## Changes

- `.github/workflows/ci.yml`: five jobs (pytest + 75% coverage gate on
  3.11/3.12, compileall + shell-injection grep gate, golden-sync, UI
  lint/vitest/build, example smoke). No secrets; `contents: read`.
- `scripts/generate-golden.py`: deterministic single source for
  `tests/contract/golden/` (Phase 2 full/minimal RunRecord, DecisionReport,
  TraceRef, EvaluationResult, RunPlan, legacy v0.1.x) and the P0 canonical
  fixture at its original path (release preflight unchanged).
- `tests/contract/test_golden.py` (25 cases): round-trip, idempotency,
  no-secret/no-home-path assertions.
- `ui/src/lib/__tests__/golden-contract.test.ts` (23 cases): zod parse +
  stripped-field detection.
- Removed hand-maintained ui fixtures and `tests/fixtures/legacy/`;
  consumers migrated to golden paths.
- `pytest-cov` added to the dev dependency group.

## Review findings (fixed in main session)

- Subagent left the golden-sync job as plain `git diff --exit-code`, which
  silently passes for newly generated (untracked) golden files; hardened to
  `git add -A` + `git diff --cached --exit-code`.
- Drift experiment 1 could not have been verified pre-commit (git diff is
  blind to untracked files); re-ran both experiments after committing.

## Verification

- pytest 147 passed (coverage 77.8% ≥ 75% gate); vitest 41 passed;
  lint/build green; golden regeneration idempotent; version consistency pass.
- Drift experiment 1: generator field added without committing golden →
  golden-sync check exit 1.
- Drift experiment 2: golden containing an undeclared field → vitest strict
  check fails with "zod silently stripped these fields".
- All experiment changes reverted; final tree regenerates clean.

## Security Checklist

- CI has zero secrets and a read-only token; tests remain network-free.
- Golden generator reads no environment variables; generated files are
  asserted to contain no `MICRO_EVAL_SECRET` markers or home-directory paths.
- No subprocess or shell-interpolation changes; grep gate enforced in CI.
