# Development Log - v0.4.4 Release

## Summary

Prepared v0.4.4 for disciplined projection from `dev` to `main` after aligning version surfaces and synchronizing the bilingual example documentation.

## Context

The release scope adds two runnable examples, expands configuration coverage, and updates the docs-site example indexes. Release preparation also corrected the tracked capability count from 40 to the 43 rows present in the source matrix.

## Changes

- Generated the v0.4.4 dependency inventory.
- Built and validated v0.4.4 wheel and sdist artifacts.
- Added release evidence for the preflight and main projection gates.
- Updated the v0.4.4 CHANGELOG date and documentation coverage statement.

## Decisions

- Keep `VERSION` as the version source of truth.
- Publish `main` only through `scripts/release-to-main.sh` from a clean `dev` checkout.
- Let the GitHub Pages workflow deploy the site from the projected `main` content.

## Verification

See `docs/releases/2026-07-12-v0.4.4-release-evidence.md`.

## Risks and follow-ups

- GitHub Pages deployment is asynchronous after the `main` push and must be checked separately.
- Conversational scoring still requires DeepEval and an external LLM provider.
