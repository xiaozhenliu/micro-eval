# micro-eval examples

## Source-checkout examples

This directory contains source-checkout examples for `micro-eval`.

> Scope note: examples are repository/source assets for this MVP. They are not
> currently bundled into the wheel, and the Next.js UI assets are still launched
> from a source checkout.

## Available use cases

| Use case | What it demonstrates |
| --- | --- |
| [Agent Codefix Showdown](agent-codefix-showdown/) | A complete MVP run over one local code-fix task, with a real-agent matrix for Claude Code, Codex CLI, OpenClaw, and Hermes plus a deterministic mock smoke path. |

Start with the use case README, then run the commands from that example directory.
